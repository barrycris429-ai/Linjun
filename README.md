# LinjunFRAMGLASS

Windows 游戏帧率、延迟与硬件监测悬浮窗，支持纯文字透明显示和手动保存游戏记录。

**[下载最新版安装包](https://github.com/barrycris429-ai/Linjun/releases/latest)**

在发布页面的 **Assets（附件）** 中下载 `LinjunFRAMGLASS-版本-Setup-x64.exe`。`Source code` 是 GitHub 自动生成的仓库文档压缩包，不能用于安装软件。

## 系统要求与安装

- Windows 10 2004 或更新版本、Windows 11；Intel/AMD x64 电脑。
- 下载并双击安装包，从桌面或开始菜单启动，确认 Windows 管理员权限提示。
- 不需要安装 VS Code、Visual Studio、RTSS 或额外的 C++ 运行库；所需采集组件已包含在安装包内。
- 当前版本为 **0.6.0**，安装包约 **3.15 MiB**。

## 主要功能

- 实时显示目标游戏的提交 FPS、参考延迟，以及可用的 CPU/GPU 温度和占用率、CPU 型号。
- 独立置顶悬浮窗，可拖动、锁定后鼠标穿透；支持纯文字透明模式、大小和不透明度调整。
- 记录默认关闭，手动开启后每次最多 30 分钟，每个游戏保留最近三份，受管记录总额度 20 MiB。
- 报告保存在“文档 → LinjunFRAMGLASS → 游戏记录”，支持从软件打开文件夹、离线 HTML 报告及 CSV 导出。

## 快速开始

1. 启动游戏和 LinjunFRAMGLASS。
2. 右键悬浮窗或托盘图标，选择“选择游戏进程”，选中正在运行的游戏。
3. 建议游戏使用“无边框全屏”或“窗口”模式。
4. 按需调整悬浮窗位置并锁定；按 `Ctrl + Alt + F10` 解锁。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + Alt + F7 | 开始记录 / 停止并保存 |
| Ctrl + Alt + F8 | 普通面板 / 纯文字透明模式 |
| Ctrl + Alt + F9 | 显示 / 隐藏 |
| Ctrl + Alt + F10 | 锁定 / 解锁；隐藏时恢复显示 |
| Ctrl + Alt + F12 | 保存当前记录后退出 |

快捷键被占用时可使用右键或托盘菜单。单击托盘图标也可显示并解锁面板。

## 当前兼容范围

- 普通置顶窗口无法保证覆盖真正的独占全屏；CS2 独占全屏无法显示是当前已知限制。
- FPS 为提交帧率，可能包含生成帧，不等同于单独的原生渲染 FPS。
- 延迟显示带来源标注的参考值，不代表完整的鼠标到屏幕实测延迟；缺少有效数据时显示“—”。
- GPU 温度与占用率目前主要支持 NVIDIA；CPU 温度依赖机型接口，当前在 MSI 机型上验证。缺少传感器时显示“—”，不影响 FPS 采集。
- 软件通过 Windows ETW 和随附的官方 PresentMon 命令行组件采集，不使用游戏注入或自带内核驱动。不同游戏及反作弊环境的兼容性仍需实际验证。
- 当前安装包与主程序未做代码签名，Windows 可能显示“未知发布者”。可使用发布附件中的 `SHA256SUMS.txt` 核对下载文件。
