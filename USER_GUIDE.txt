LinjunFRAMGLASS
游戏帧率、延迟与硬件监测

第一次使用
1. 从桌面或开始菜单启动 LinjunFRAMGLASS，并手动确认 Windows 管理员提示。
2. 先启动游戏，右键面板或托盘 →“选择游戏进程”，选中正在运行的游戏。
3. 建议游戏使用“无边框全屏”或“窗口”模式。普通置顶面板无法保证覆盖真正的独占全屏。

快捷键
Ctrl + Alt + F7   开始记录 / 停止并保存
Ctrl + Alt + F8   普通面板 / 纯文字透明显示
Ctrl + Alt + F9   显示 / 隐藏
Ctrl + Alt + F10  锁定 / 解锁（锁定后鼠标穿透）
Ctrl + Alt + F12  保存当前记录后退出

快捷键被其他程序占用时，可以使用右键或托盘菜单。单击绿色折线托盘图标可显示并解锁面板。

记录与打开
记录默认关闭，手动开启后一次最多 30 分钟。游戏退出、切换目标、暂停或退出工具时也会结束并保存。
默认位置：文档 → LinjunFRAMGLASS → 游戏记录。
右键“最近记录”打开离线 HTML 报告，或“打开记录文件夹”直接定位。报告和右键菜单均支持 CSV 导出。
每游戏最多保留最近三份，受管记录总额度 20 MiB。主动移走的报告和导出的 CSV 不会被软件清理。
异常退出后可从右键“恢复未完成记录”恢复；最近约十秒尚未刷出的数据可能丢失。

显示与兼容性
提交 FPS 可能包含生成帧，不等于单独的原生渲染 FPS。
延迟优先使用“游戏 PC”标记，缺失时使用“输入估算”；没有有效数据时显示“—”。
CPU 占用率为全机读数；目前 GPU 温度与使用率主要支持 NVIDIA 驱动接口。
CPU 温度依赖机型提供的接口，当前在 MSI 机型上验证；其他品牌或型号可能显示“—”。缺失传感器不影响 FPS 采集。
本软件不使用游戏注入、图形 API 挂接、自带内核驱动或读取游戏私有内存；不同游戏的反作弊兼容性仍需实际验证。

安装、更新与卸载
面向 Intel/AMD x64 电脑，支持 Windows 10 2004 / Windows 11 或更新版本。
不需要安装 VS Code、Visual Studio、C++ 运行库或完整 PresentMon。安装包已包含所需采集组件。
更新或卸载前请先退出 LinjunFRAMGLASS，正在记录的数据会保存。
可在 Windows 设置 → 应用，或开始菜单的卸载入口移除软件。卸载保留文档中的报告及个人设置。
软件不会自动开机启动，也不会安装常驻采集服务或自动启用记录。

分发说明
